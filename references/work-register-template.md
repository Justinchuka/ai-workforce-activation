# Work Register Template

One central table. Keep it short and current.

| ID | Task / project | Objective | Dept | Owner | Support | Priority | Deadline | Deliverable | Dependencies | Status | Next action |
|---|---|---|---|---|---|---|---|---|---|---|---|

## Status labels
PROPOSED, APPROVED, IN PROGRESS, COMPLETED, ON HOLD, BLOCKED, SUPERSEDED.

## Rules
- Prioritise the user's most important objectives; break large work into assignments someone can finish.
- Start when there is enough information; carry unfinished work forward; track deadlines and dependencies.
- A recommendation is not an assignment; a draft is not a submission; mark COMPLETED only with evidence.
- Retire superseded items as SUPERSEDED instead of deleting.
- Measure by outcomes relevant to the mission (clients, revenue, applications, partnerships, content, time saved), not task counts.
